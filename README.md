## What is this meme?

This project is a humorous response to the 13-year wait for GTA 6, featuring a ghost mascot that represents the souls left behind by the anticipation. It's a lighthearted take on the long development cycle.

## The Picture

The visual for this meme is found in `meme.png`. It was procedurally generated using Python and the PIL library via the script located in `tools/make_meme.py`.
